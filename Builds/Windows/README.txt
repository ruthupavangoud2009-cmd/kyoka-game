KYOKA — Windows Standalone Release
==================================

How to Play:
Double-click "PLAY_KYOKA.bat" or "KYOKA.exe" to launch the game.

Controls:
- WASD: Move
- Mouse: Look / Aim
- Left Shift: Sprint
- Space: Jump
- C: Crouch
- Left Click: Melee Attack Combo / Shoot Ranged Weapon
- Right Click: Guard / Defend (Reduces damage by 65%)
- Q: Wind Tempest Dash
- F: Flame Surge
- R: Thunder Strike
- T: Kyoka Awakening (Transformation)
- E: Enter / Exit Vehicle or Interact
- V: Toggle First-Person / Third-Person Camera
- Tab / I: Inventory
- M: World Map & Teleport
- Esc: Pause Menu / Settings

For updates and source code, visit:
