# KYOKA — Unity Project Starter

This is an editable Unity project scaffold for Antigravity to continue developing.

## Open it
1. Extract `KYOKA_Full_Unity_Project.zip`.
2. Open Unity Hub.
3. Choose **Add > Add project from disk**.
4. Select the extracted `KYOKA_Full_Unity_Project` folder.
5. Open it with Unity 6 (6000.0 or newer).
6. Let Unity import and resolve packages.
7. Open `Assets/KYOKA/Scenes/KYOKA_Bootstrap.unity` if it was generated by the editor setup script, then press Play.

If the scene has not been generated yet:
- In Unity, use **KYOKA > Create / Repair Bootstrap Scene** from the top menu.
- Then open `Assets/KYOKA/Scenes/KYOKA_Bootstrap.unity` and press Play.

## What is implemented
- Runtime bootstrap and test island generation.
- Third-person / first-person camera toggle.
- CharacterController movement.
- Keyboard controls and basic mobile UI buttons/joystick.
- Fictional ability framework with cooldowns.
- Health and training dummy.
- Vehicle enter/exit prototype and vehicle controller.
- Inventory and item definitions.
- Mission objective framework.
- Basic world region manager.
- Creative placement prototype.
- Survival resource gathering and crafting data.
- Battle royale match-state prototype.
- Local JSON save/load.
- Runtime HUD and debug menu.
- EditMode tests for core data logic.

## Important limitations
This is a substantial starter codebase, not a finished commercial game.
- Online multiplayer is **not** claimed to work yet. The networking folder contains a clear integration boundary and implementation plan.
- The generated environment is greybox/procedural starter geometry, not final art.
- No production backend, matchmaking service, dedicated servers, anti-cheat, final character art, final vehicle art, or final maps are included.
- iOS and Android builds must be configured and tested in Unity on suitable hardware.
- Free service tiers have limits. Do not add paid services without approval.

## Controls
- WASD: move
- Mouse: look
- Left Shift: sprint
- Space: jump
- V: switch first/third person
- E: interact / enter or exit vehicle
- Q: use sample ability
- Escape: unlock cursor
